# YourFlareMails infra

Local Wrangler config, D1 migrations, and seeds.

| Path | Purpose |
| --- | --- |
| `wrangler.jsonc` | Local D1/R2 placeholders |
| `wrangler.deploy.jsonc` | Generated by `pnpm deploy:configure` (gitignored) |
| `migrations/` | D1 SQL migrations |
| `seed/seed.sql` | Local seed (`hello@example.com`) |
| `seed/seed-prod.example.sql` | Template → copy to `seed-prod.sql` (gitignored) |
| `scripts/apply-deploy-config.mjs` | Build deploy configs from `config/deploy.local.env` |
| `scripts/hash-password.mjs` | PBKDF2 hash for production seed |

```bash
pnpm db:migrate
pnpm db:seed
pnpm deploy:configure   # after filling config/deploy.local.env
```

Full production steps: [docs/deploy.md](../docs/deploy.md).
